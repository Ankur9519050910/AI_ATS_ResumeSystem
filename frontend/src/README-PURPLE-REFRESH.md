# ResumeAI Purple UI Refresh

This update improves readability and adds a more colorful purple gradient visual style to the existing frontend.

## Changes
- Stronger, more readable Manrope typography and heavier headings
- Purple, violet, pink, and lavender color palette
- Gradient primary buttons and hero heading
- More colorful resume preview card and progress bars
- Improved feature cards and CTA section
- Stronger contrast and typography across dashboard, analyzer, auth, and results screens

## Apply
Back up your existing `frontend/src` directory, then replace it with the `src` directory in this ZIP. The backend and npm dependencies are not changed.

Run from the frontend directory:

```bash
npm run dev
```
